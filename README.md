3. ## Give two practices that can reduce unnecessary Git conflicts on a real team.
   One practice that will help reduce unnecessary conflicts would be communication between team members to make sure they are not working on the same lines of code. The other practice would be pulling before starting work to make sure you are on the most up to date version.
